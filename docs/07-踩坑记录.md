## 1. 舵机完全不动 —— 协议帧格式错误 ⭐ 最隐蔽

### 现象

```
· 舵机 LED 常亮（有电）
· 串口命令能发出去（STM32 回 OK）
· 但舵机完全不转、不应答
· 试了 20+ 种波特率、时序、接线，全都没用
```

### 原因

我凭记忆写 LX-16A 协议，**在运动指令里多加了 2 字节「速度」参数**：

```
错误的帧：
55 55 01 07 01 F4 01 00 00 00 00 CS
          ↑      ↑──────┬───────┘
        长度7      多加了速度 2 字节

正确的帧（官方）：
55 55 01 07 01 F4 01 E8 03 16
          ↑      ↑─────┬───┘
        长度7    角度 + 时间 = 4 字节
```

**Length 必须满足**：`Length = ID(1) + Cmd(1) + 参数长度 + 校验和(1)`

参数长度错了 2 字节 → 舵机认为包不合法 → **静默丢弃**。

### 教训

> **协议文档必须逐字节核对，写完先用官方例子对比。**

调试技巧：把发出去的帧打印成十六进制，和官方例子逐字节比对。

## 2. 摄像头突然消失 —— 系统更新重置配置

### 现象

```
· 之前摄像头正常
· 跑了 `apt upgrade`（894 个包）
· 重启后摄像头完全不见了
· i2cdetect 什么都看不到
```

### 原因

`/boot/extlinux/extlinux.conf` 被系统更新重置：

```diff
- DEFAULT JetsonIO     ← 加载摄像头设备树 overlay
+ DEFAULT primary       ← 恢复默认，摄像头驱动不加载
```

### 修复

```bash
sudo sed -i 's/^DEFAULT primary$/DEFAULT JetsonIO/' /boot/extlinux/extlinux.conf
sudo reboot
```

### 教训

> **Jetson 上任何系统更新后，先检查 extlinux.conf 的 DEFAULT。**

## 3. 舵机收不到信号 —— 面包板不同排

### 现象

```
· 舵机有电（LED 亮）
· 命令能发
· 但舵机毫无反应
```

### 原因

PA2 和 PA3 的杜邦线插在**面包板的两个不同横排**，两排不连通。

### 排查方法（关键）

用 `LOOP` 回环自测命令：

```
LOOP  →  PA2 发 0x55，PA3 收
       →  收到 0x55 = 接线正常
       →  收不到 = PA2/PA3 没连通
```

### 教训

> **面包板的"排"是横着一整行（5 个孔连通），不同行不通。**
> **用「发什么收什么」的自测，能 5 秒定位线路问题。**

## 4. FlyMcu 自动烧录点不动 —— 窗口被遮挡

### 现象

用 Win32 API 找到按钮句柄，发送 `BM_CLICK`，但毫无反应。

### 排查过程

1. **UI Automation 找按钮** → 找到 0 个（Delphi 程序不暴露控件）
2. **SendKeys 发快捷键** → 无反应（窗口没焦点）
3. **BM_CLICK 消息** → 无反应（Delphi 自绘按钮不响应标准按钮消息）
4. **真实鼠标点击** → 还是无反应
5. **截图看屏幕** → **发现 FlyMcu 被其他窗口完全挡住了！**

鼠标点击点在遮挡窗口上，根本没点到 FlyMcu。

### 解决

```powershell
# 1. 把窗口移到屏幕左上角并置顶
[W]::SetWindowPos($main, [IntPtr](-1), 30, 30, 720, 560, 0x0040)

# 2. 激活窗口
[W]::SetForegroundWindow($main)

# 3. 找到按钮的屏幕坐标，真实鼠标点击
[W]::GetWindowRect($btn, [ref]$r)
[W]::SetCursorPos(($r.Left+$r.Right)/2, ($r.Top+$r.Bottom)/2)
[W]::mouse_event(0x0002, 0, 0, 0, [UIntPtr]::Zero)   # LEFTDOWN
[W]::mouse_event(0x0004, 0, 0, 0, [UIntPtr]::Zero)   # LEFTUP
```

### 教训

> **GUI 自动化失败时，先截图看屏幕实际状态。**
> **Delphi/VCL 程序的按钮不响应 BM_CLICK，必须用真实鼠标事件。**

## 5. 拍照全黑/纯噪声 —— 自动曝光未收敛

### 现象

```
拍出来的照片是全黑 / 纯噪声 / 纯绿
```

### 原因

CSI 摄像头上电后，**自动曝光（AE）和自动白平衡（AWB）需要几十帧才收敛**。直接抓第 1 帧拿到的是未收敛的画面。

### 解决

```bash
# 预抓 90 帧，只保留最后一帧
gst-launch-1.0 -e nvarguscamerasrc sensor-id=0 num-buffers=90 \
    ! "video/x-raw(memory:NVMM),width=1920,height=1080,format=NV12" \
    ! nvjpegenc ! multifilesink location=/tmp/f_%03d.jpg
# 取 /tmp/f_089.jpg
```

### 教训

> **摄像头"第一帧"永远不可信。至少预热 40 帧，90 帧更稳。**

## 6. 烧录卡在"写内存" —— 自制烧录器失败

### 现象

```
✅ 进入 bootloader（0x7F → ACK）
✅ 读芯片 ID（0x02）
✅ 读内存（0x11）
✅ 全片擦除（0x43）
❌ 写内存（0x31）—— 长度字节无应答，数据 NACK
```

### 尝试过的方法（全部失败）

- 不同波特率（9600 / 19200 / 38400 / 57600 / 115200）
- 不同时序（加延时 / 立即发）
- 不同协议顺序（长度在地址前 / 后）
- 解除写保护（0x73）
- 按页擦除
- 整帧一次性发送
- 用 `stm32loader` Python 库

### 解决

**放弃自制，改用官方推荐的 FlyMcu** —— 一次成功。

### 教训

> **当自制工具在某个步骤反复失败时，先换成熟工具验证硬件没问题。**
> **不要在错误的方向上越挖越深。**

## 7. 舵机突然全部不响应 —— 电池耗尽

### 现象

连续测试 2 分钟后，两个舵机同时失去响应。

### 原因

**7.4V 锂电池耗尽**（舵机连续转动耗电很大）。

### 教训

> **舵机测试要留意电池电量。连续转动 2~3 分钟就可能耗尽。**
> **电池耗尽时舵机不会报错，只是静默不响应。**

## 8. PowerShell 吞引号 —— 远程命令全是错

### 现象

```powershell
ssh nvidia@... "python3 -c 'import servo; ...'"
# → bash: -c: 行 1: 未预期的记号 "(" 附近有语法错误
```

### 原因

PowerShell 会处理引号和多行字符串，导致传给 SSH 的命令被破坏。

### 解决

**把脚本写成文件，用 scp 上传后执行：**

```powershell
# 1. 本地写脚本
Set-Content test.py -Value $content
# 2. 上传
scp test.py nvidia@192.168.55.1:/home/nvidia/project/
# 3. 执行
ssh nvidia@192.168.55.1 "cd /home/nvidia/project && python3 test.py"
```

### 教训

> **复杂的远程命令不要内联，写成文件传输。**

## 9. 舵机位置读数出现 65534 —— 有符号数

### 现象

```
舵机转到 0 时，读位置返回 65534
```

### 原因

舵机顶到机械限位时有 **-2 的负过冲**，用无符号 16 位解析就变成 65534 (`0xFFFE`)。

### 解决

```python
v = data[i+5] | (data[i+6] << 8)
return v - 65536 if v > 32000 else v   # 65534 → -2
```

### 教训

> **舵机的位置是 16 位，但边界处会出现负数。**

## 📋 排查清单（遇到问题时按顺序查）

```
舵机不动？
├─ 1. STM32 还在吗？        → 发 PING，看回不回 PONG
├─ 2. 信号线通吗？          → 发 LOOP，看能不能收到 0x55
├─ 3. 舵机有电吗？          → 看 LED（亮/闪/灭）+ 手转有阻力吗
├─ 4. 舵机应答吗？          → 发 R1，看有没有 8 字节应答
├─ 5. 帧格式对吗？          → 打印 TX 十六进制，和官方例子比对
└─ 6. 电池还有电吗？        → 充电试试
```
