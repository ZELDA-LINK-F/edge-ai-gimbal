# 系统架构

## 三层架构

```
感知层 ──→ 决策层 ──→ 执行层
```

### 感知层（Jetson）

- **硬件**：IMX219 CSI 摄像头（1920×1080@30fps）
- **软件**：`camera.py` 提供三种取帧模式
  - `photo()`：多帧预热拍照（90 帧后取最后一帧，解决自动曝光未收敛）
  - `video()`：H.264 硬件编码录像
  - `frames()`：连续取帧生成器（给检测用）

### 决策层（Jetson）

- **YOLOv8n**：6.25MB 模型，TensorRT FP16 引擎
- **输入**：1280×720 BGR 帧
- **输出**：检测框列表
- **跟随算法**：
  ```
  人的水平中心 x → 归一化偏移 [-1, +1]
       → 映射到舵机目标位置
       → 平滑滤波（避免抖动）
  ```

### 执行层（STM32 + 舵机）

- **STM32F103VET6**：裸机固件，串口命令解析
- **LX-16A 舵机**：半双工 UART 总线，115200bps

---

## 数据流

```
摄像头帧 (1280×720 BGR)
    ↓ 27ms
YOLO 检测 → person box (x1,y1,x2,y2)
    ↓ <1ms
偏移计算 → cx=532, offset=-0.17
    ↓ <1ms
目标位置 → pan_target=483
    ↓ <1ms
平滑滤波 → pan=496.5
    ↓ 串口 8 字节
"S1,496,200\r\n"
    ↓ 115200bps
STM32 解析 → LX-16A 帧 (10 字节)
    ↓ 115200bps
舵机转动
```

**端到端延迟 < 50ms**

## 通信协议

### Jetson ↔ STM32（文本协议）

| 命令 | 功能 | 示例 |
|---|---|---|
| `PING` | 心跳检测 | → `PONG` |
| `S<id>,<pos>` | 舵机运动 | `S1,500` |
| `S<id>,<pos>,<ms>` | 带时间 | `S1,500,1000` |
| `S254,<pos>` | 广播 | `S254,500` |
| `R<id>` | 读位置 | `R1` |
| `ID<旧>,<新>` | 改 ID | `ID1,2` |
| `LD<id>,<0\|1>` | 卸载/装载 | `LD1,1` |
| `SCAN` | 扫描 ID 1~20 | |
| `LOOP` | 回环自测 | |
| `BAUD` | 波特率扫描 | |
