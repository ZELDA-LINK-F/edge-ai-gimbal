# 硬件接线

## 总览

```
        7.4V 锂电池                 LX-16A 舵机 ×2
        ┌──────────┐              ┌────────────────┐
        │  红 (+)  │──────────────│ 红 VIN         │
        │  黑 (−)  │──┬───────────│ 黑 GND         │
        └──────────┘  │           │ 白 SIG         │
                      │           └───────┬────────┘
                      │                   │
                      │     ┌─────────────┘
                      │     │
                      │  面包板（信号排）
                      │     ├── 舵机 SIG
                      │     ├── 杜邦线 → PA2
                      │     └── 杜邦线 → PA3
                      │
                      └──── 面包板（负极轨）
                             ├── 电池黑线
                             ├── 舵机 GND
                             └── 杜邦线 → 板子 GND
```

---

## 关键：必须共地

> 当舵机和单片机使用的不是同一个电源时，**要将两个电源共地**。

**原因**：UART 信号电平是相对于各自的地判断的。两个地不连通 = 没有共同零点 = 信号错乱。

**实现**：用面包板把「电池负极」「舵机 GND」「板子 GND」接到同一条负极轨。

## 野火指南者引脚位置

### JP5（板子右侧，2×6 排针）

```
        靠板子中间        靠板子边缘
         （左列）          （右列）
第1行    B6                B7
第2行    B5                A8
第3行    A2  ← PA2         A11
第4行    A3  ← PA3         A12
第5行    B10               URX
第6行    B11               UTX
```

### JP4（JP5 正上方，2×6 排针）

```
        靠板子中间        靠板子边缘
第1行    A4                A5
第2行    A6                A7
第3行    E5                E6
第4行    C13               C4
第5行    B0                GND  ← 板子 GND
第6行    5V                3V3
```

## 接线表

| # | 从 | 到 | 位置 |
|---|---|---|---|
| 1 | 电池 **红(+)** | 舵机 **红 VIN** | 面包板正极轨 |
| 2 | 电池 **黑(−)** | 舵机 **黑 GND** | 面包板负极轨 |
| 3 | 电池 **黑(−)** | **板子 GND** | **JP4 第5行靠边** |
| 4 | 舵机 **白 SIG** | **PA2** | **JP5 第3行靠中间** |
| 5 | 舵机 **白 SIG** | **PA3** | **JP5 第4行靠中间** |

> 第 4、5 两线需要汇合 —— 用面包板同一横排（一排 5 个孔连通）。

## 无电阻的信号方案

传统做法要在 TX 和信号线之间串 1kΩ 电阻，防止 MCU 和舵机同时驱动总线。

本项目**不用电阻**，而是利用 STM32 的 GPIO 模式切换：

```c
/* 发送前：推挽输出（强驱动，不需要上拉）*/
pa2_drive(1);   // AF 推挽 50MHz

/* 发送 → 等待 TC（最后一个字节完全移出）*/
while (!(USART2->SR & USART_SR_TC)) {}

/* 发完立刻切高阻（舵机应答时不会冲突）*/
pa2_drive(0);   // 浮空输入
```

**PA3 配置为输入上拉**，为总线提供空闲高电平。

⚠️ **注意**：如果长时间收不到舵机应答，检查 PA3 是否真的和信号线连通（用 `LOOP` 命令自测）。

## ⚠️ 安全警告

| 危险操作 | 后果 |
|---|---|
| **SIG 接到电源正极（7.4V）** | 烧舵机信号输入，可能烧 STM32 IO |
| **VIN/GND 接反** | 烧舵机 |
| **不共地** | 通信失败（不会烧，但完全不工作） |
| **舵机由板子 5V 供电** | 电流过大导致板子重启 |

## 摄像头排线注意事项

**IMX219 使用 15pin 转 22pin FPC 硬排线**，反复弯折会导致内部铜箔断裂。

**保护措施**：
1. **限制旋转角度**（软件限位 ±24°）
2. **走线靠近转轴**（转动时是「扭转」而不是「弯折」）
3. **固定线缆根部**（用胶带/扎带，让力作用在固定点而非连接器）
4. **留一段松弛的弯**（服务环）
