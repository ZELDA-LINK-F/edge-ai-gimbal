# 云台跟随

## 核心逻辑

```
摄像头帧 (1280×720)
    ↓
[180° 翻转]   ← 摄像头装反了
    ↓
YOLO 检测
    ↓
找最大的 person
    ↓
算水平中心 cx
    ↓
归一化偏移 offset = (cx - 640) / 640   → [-1, +1]
    ↓
目标位置 target = 500 + offset × (PAN_MAX - PAN_MIN) / 2
    ↓
平滑滤波 pan = pan + (target - pan) × SMOOTH
    ↓
安全限位 clamp(pan, 400, 600)
    ↓
串口发送 "S1,<pan>,200"
    ↓
舵机转动
```

---

## 关键参数

```python
W, H = 1280, 720          # 检测分辨率
CONF = 0.4                # 置信度阈值
UPSIDE_DOWN = True        # 180° 翻转（摄像头装反时用）

PAN_ID = 1                # 水平舵机 ID
PAN_MIN, PAN_MAX = 400, 600   # 安全限位
PAN_CENTER = 500          # 中位
SMOOTH = 0.25             # 平滑系数
MOVE_MS = 200             # 舵机运动时间
```

### 平滑系数 SMOOTH 怎么调

| 值 | 效果 |
|---|---|
| 0.1 | 很平滑，但有滞后 |
| **0.25** | **平衡（推荐）** |
| 0.5 | 灵敏，但可能抖动 |
| 1.0 | 每帧直接到位（可能抖动/异响） |

---

## 安全限位（重要）

**摄像头 FPC 排线不能反复弯折**，所以默认限制在 ±24°：

```python
PAN_MIN, PAN_MAX = 400, 600     # ±100 单位 = ±24°
```

### 角度换算

```
位置 0~1000  →  0~240°
1 单位  =  0.24°
±100 单位  =  ±24°
```

### 需要更大角度时

```python
# 1. 先确认排线走线有余量（靠近转轴 + 固定根部）
# 2. 再逐步放宽
PAN_MIN, PAN_MAX = 350, 650     # ±36°
```

### 临时绕过限位

```python
bus.move(1, 300, bypass=True)   # 强制超出安全范围
```

## 完整跟随代码（核心部分）

```python
def step(self):
    ok, frame = self.cap.read()
    if not ok:
        return
    if self.flip:
        frame = cv2.rotate(frame, cv2.ROTATE_180)

    dets, dt = detect_frame(self.model, frame, conf=0.4)
    person = self.biggest_person(dets)

    if person:
        x1, y1, x2, y2 = person["box"]
        cx = (x1 + x2) / 2.0
        offset = max(-1.0, min(1.0, (cx - 640) / 640.0))
        target = 500 + offset * (600 - 400) / 2.0
        self.pan = self.pan + (target - self.pan) * 0.25

        # 快速发送（不等应答）
        p, _ = self.bus.clamp(1, self.pan)
        self.bus.s.write(("S1,%d,200\r\n" % p).encode())
    else:
        # 没人 → 慢慢回中
        self.pan = self.pan + (500 - self.pan) * 0.1
        self.bus.s.write(("S1,%d,400\r\n" % int(self.pan)).encode())
```

---

## 为什么用「快速发送」而不是 `bus.move()`

`bus.move()` 会等待舵机应答（约 400ms），太慢，跟不动。

跟随循环里直接写串口，不等应答：

```python
self.bus.s.write(("S1,%d,200\r\n" % p).encode())
```

同时每 2 秒清一次接收缓冲（固件会回显 `TX:` / `OK` / `HELLO`）：

```python
def drain(self):
    if time.time() - self.last_drain > 2.0:
        self.bus.s.reset_input_buffer()
        self.last_drain = time.time()
```
