# STM32 固件

## 特点

- **裸机**：无 HAL/标准外设库，直接操作寄存器
- **从零构建**：手写启动文件、中断向量表、链接脚本
- **体积小**：编译产物仅 4.5KB
- **无依赖**：只需要 arm-none-eabi-gcc

---

## 文件结构

| 文件 | 说明 |
|---|---|
| `main.c` | 主程序：时钟、串口、SysTick、命令解析、舵机协议 |
| `startup.c` | 启动文件：中断向量表、Reset_Handler |
| `linker.ld` | 链接脚本：512K Flash @ 0x08000000，64K RAM @ 0x20000000 |
| `Makefile` | 编译脚本 |
| `flash.ps1` | FlyMcu 自动烧录脚本 |

## 系统初始化顺序

```c
int main(void)
{
    clock_init();       // 1. 时钟：HSE 8MHz × 9 = 72MHz
    gpio_usart_init();  // 2. GPIO + USART1/USART2
    systick_init();     // 3. SysTick 1ms 系统时钟

    u1_puts("STM32F103VET6 READY\r\n");

    // 4. 主循环
    while (1) {
        while (u1_getc(&c)) { /* 处理串口命令 */ }
        if (millis() - last_beat >= 1000) { /* 心跳 */ }
    }
}
```

## 时钟配置

```
HSE 8MHz → PLL ×9 → 72MHz
APB1 = 36MHz（USART2 时钟）
APB2 = 72MHz（USART1 时钟、GPIO）
```

**注意**：USART1 在 APB2（72MHz），USART2 在 APB1（36MHz），所以波特率寄存器值不同：

```c
USART1->BRR = 625;   // 72MHz / 115200 = 625
USART2->BRR = 312;   // 36MHz / 115200 = 312.5
```

## 串口配置

| 串口 | 引脚 | 用途 | 波特率 |
|---|---|---|---|
| USART1 | PA9(TX) / PA10(RX) | 与 PC/Jetson 通信 | 115200 8N1 |
| USART2 | PA2(TX) / PA3(RX) | LX-16A 舵机总线 | 115200 8N1 |

### PA2 的特殊处理（无电阻方案）

```c
static void pa2_drive(int on)
{
    if (on) GPIOA->CRL = (GPIOA->CRL & ~(0xFU<<8)) | (0xBU<<8);   // AF 推挽
    else    GPIOA->CRL = (GPIOA->CRL & ~(0xFU<<8)) | (0x4U<<8);   // 浮空输入（高阻）
}
```

**发送流程**：
1. `pa2_drive(1)` — 切推挽
2. 发送帧
3. 等待 `TC` 标志（最后一个字节移位完成）
4. `pa2_drive(0)` — 切高阻，让出总线

## 命令解析

主循环采用**非阻塞轮询 + 行缓冲**，避免丢字符：

```c
char line[80];
int li = 0;
while (u1_getc(&c)) {
    if (c == '\r' || c == '\n') {
        if (li > 0) {
            line[li] = 0;
            handle_command(line);   // 处理完整一行
            li = 0;
        }
    } else if (li < sizeof(line) - 1) {
        line[li++] = c;
    }
}
```

> ⚠️ 第一版固件用了 `delay_ms(1)`，导致每秒只能处理 1 个字符 —— 115200 波特率下严重丢字符。改成非阻塞后解决。

## 心跳

每秒打印一次 `HELLO <n>`，用于确认固件在运行。

```c
if (millis() - last_beat >= 1000) {
    last_beat = millis();
    beat++;
    u1_puts("HELLO ");
    u1_putu(beat);
    u1_puts("\r\n");
}
```

## 诊断命令

| 命令 | 作用 | 使用场景 |
|---|---|---|
| `LOOP` | PA2 发 0x55，PA3 收 | 验证信号线是否连通 |
| `SCAN` | 扫描 ID 1~20 | 找舵机真实 ID |
| `BAUD` | 扫 9600~1000000 | 找舵机波特率 |
| `R<id>` | 读位置并回显原始字节 | 调试协议 |

**`LOOP` 是最有用的**：如果 PA2 和 PA3 短接（同一根线），发什么应该收到什么。收不到就说明接线断了。

## 编译

```bash
arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -O2 -Wall -Wextra \
    -nostdlib -ffreestanding -c startup.c -o startup.o

arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -O2 -Wall -Wextra \
    -nostdlib -ffreestanding -c main.c -o main.o

arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -T linker.ld -nostdlib \
    -Wl,--gc-sections -o firmware.elf startup.o main.o

arm-none-eabi-objcopy -O ihex firmware.elf firmware.hex
```

## 烧录

野火指南者有**一键 ISP 下载电路**（CH340 + DTR/RTS 控制 BOOT0/NRST）。

**手动**：用 FlyMcu，配置 COM 口、115200、选 hex、去掉「选项字节」勾选、点「开始编程」。

**自动**：`flash.ps1`（见 [07-踩坑记录.md](07-踩坑记录.md) 的自动化部分）

## 关键寄存器速查

```c
// 时钟
RCC->CR    |= (1<<16);              // HSEON
RCC->CFGR   = (1<<16) | (7<<18);    // PLLSRC | PLLMULL9
RCC->CFGR  |= (4<<8);               // PPRE1 = /2

// GPIO 模式（每引脚 4 bit）
// 0000=输入模拟 0100=输入浮空 1000=输入上拉/下拉
// 0011=输出推挽50M  1011=AF推挽50M  1111=AF开漏50M
GPIOA->CRL = (GPIOA->CRL & ~(0xF<<8)) | (0xB<<8);   // PA2 = AF推挽

// USART
USART1->BRR = 625;
USART1->CR1 = (1<<13) | (1<<3) | (1<<2);   // UE | TE | RE

// SysTick（1ms）
SYSTICK->LOAD = 9000 - 1;   // 72MHz/8 = 9MHz → 9000 ticks = 1ms
SYSTICK->CTRL = 3;          // ENABLE | TICKINT | HCLK/8
```
